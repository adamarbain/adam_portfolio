# Portfolio Improvement Roadmap 🚀

This list is compiled from professional feedback (recruiters, data scientists, and developers) to optimize for full-time hiring.

## 📝 1. Content & Copywriting
- [ ] **Trim Text Density:** Reduce word counts on the landing page to improve scannability. Use bullet points for project descriptions.
- [ ] **Implement "Personable" About Me:** Update the section to include the mission-driven and sports-active traits.
- [ ] **Shift to "Impact" Narratives:** For each project, answer "Why does this matter?"
    - *Example:* Instead of "Used YOLOv8," use "Implemented YOLOv8 to improve detection accuracy by X%, enabling faster health response times."
- [ ] **Update Work Status:** Ensure all references to "internship" are removed and replaced with "Full-Time Software Engineering" intent.

## 🎨 2. UI/UX & Visual Neatness
- [ ] **Color Palette:** Consider a more cohesive color scheme. The current mix of bright colors can be overwhelming. A more muted palette with 2-3 accent colors would look more professional.
- [ ] **Carousel Physics:** Fix the `swipe` sensitivity/friction on mobile. It currently moves too fast to read.
- [ ] **Visual Hierarchy:** Standardize padding, icon sizes, and font weights in the header to improve the "first impression" neatness.
- [ ] **Proof of Work:** Add high-visibility buttons for "Live Demo" and "GitHub Repository" for every project. Double confirm with me which projects have these available.
- [ ] **Routing each subheader:** Add seperate pages for "About Me", "Projects", and "Contact" instead of scrolling to sections. This allows for more content and better SEO.
- [ ] **Use ShadCN UI Components:** Standardize the design by using ShadCN components for buttons, cards, and badges across the site.


## 🛠️ 3. Technical & SEO
- [ ] **Analytics Check:** Ensure the "Visitor Tracker" is not impacting site performance/load times.
- [ ] **Responsive Audit:** Double-check the layout on different screen sizes (specifically the header and project cards).
